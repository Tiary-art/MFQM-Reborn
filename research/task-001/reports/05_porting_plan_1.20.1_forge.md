# 05 — Minecraft 1.20.1 Forge 移植设计与阶段验收

本文件是设计，不含新版源码；任务002及后续未启动。日期：2026-11-17。目标版本为 Minecraft Java 1.20.1、Forge 47.x、Java 17；具体 Forge 小版本在002锁定，不在本次构建验证。

## 坐标、时序与行为取舍

1. 先记录旧版玩家/非玩家脚部Y、眼高、AABB、表面和k，转换为版本无关浸没量。禁止直接把旧k阈值套到新版玩家Y。
2. 旧物理同时写motion、onGround、fallDistance、web与属性，存在客户端参与；新版以服务端为最终状态，客户端仅做输入与平滑。允许预测时须定义校正阈值。
3. 每实体每tick先汇总接触方块，再确定主材料/混合规则、氧气、伤害、浮力/阻力与救援，避免站在边界重复扣气或伤害。
4. 旧随机与周期调节保留为材料规则，但先用分位数/轨迹比较确认体感；不要求跨版本逐比特随机序列一致。
5. 死亡打包污染、String引用比较、NaN/Infinity、数组越界等作为显式修复项；行为差异登记，而不是作为“兼容性”盲目复刻。
6. 不保留原版注册表反射替换、全局64槽与硬编码DataWatcher ID。没有直接跨越十个大版本打开旧存档的承诺；若要迁移存档，单独设计离线转换与备份。
