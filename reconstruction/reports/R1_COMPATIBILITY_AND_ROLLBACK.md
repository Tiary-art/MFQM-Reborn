# 存档兼容与回退

R1 以 R0 的 153 个注册对象作为冻结集合；数据库验证确认它是最终运行时集合的子集。新增的 91 个独立物品都有独立资源键。已有世界中的 Mud 仍用原来方块和 depth 属性，物品栏变体使用 BlockStateTag。每个创造栏栈均通过 Minecraft ItemStack.save / ItemStack.of 往返。

Linux 单人客户端打开并保存 Phase9 测试世界的副本。专服使用隔离测试目录，经历客户端加入、退出和服务端存盘。日志包括 Forge 在加载世界时调整数字 ID 的警告。验证以命名空间 ID 为依据。用户的旧背包、离线玩家档案、未知整合包和每种旧方块状态均未逐个核对。

回退时关闭游戏和服务端，换回此前安装的 JAR，并恢复升级前世界备份。旧版本不识别 R1 新增物品。已提交的 Phase9 公开 JAR 和 R0 基线 790ddad 可用于新测试实例复查。
