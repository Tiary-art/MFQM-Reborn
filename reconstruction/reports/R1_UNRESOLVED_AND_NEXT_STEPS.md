# 剩余对象与验收条件

174 个已识别旧栈中 21 个暂无现代栈。按 CONTENT_PARITY_MATRIX 的 original_stack_id 可定位每条证据。未证实的旧运行时对象可能增加分母。

|旧对象与 damage|下一项需要验证的事实|
|---|---|
|BrownClay 1、2、3、5、6、7|原标准创造栏只列 0 和 4；其余深度需比较世界状态和掉落。|
|WaxWood 1、2、3、5、6、7|原木方向由状态编码。需比较实际放置方向、蜂蜡面和掉落。|
|Morass 9|语言表有 Moor，显式旧方法只追加 1..8。需判断是否仅有世界状态。|
|MoorGrass 1..5|确认 int 重载的真实调用者；比较草色乘数、剪切和蔓越莓阶段后再决定玩家可取得的栈。|
|Tendrils 1..3|图标可定位 Tent1..3，旧 int 重载的分派、植物形体和附着条件仍需对照。|

U-01 已找出并修复 mucus 的一个可复现案例。用户最初看到的所有异常 ID、开启的资源包和 Windows 安装尚未逐一核对。U-02 有旧语言文件与 addName 冲突，U-03 缺少 1.7.10 动态创造栏分母。三项维持 PARTIAL。U-04 的物理和 U-05 的污渍继续保留原始跟踪。下一步优先取得同一原 JAR 的旧版创造栏枚举和用户正式客户端按 ID 的比对。
