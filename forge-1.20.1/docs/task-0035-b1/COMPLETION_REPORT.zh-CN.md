# MFQM Reborn 003.5-B1 开发与验证报告

目标：Minecraft 1.20.1 / Forge 47.2.0 / Java 17。开发分支：`task/0035-b1-motion`。基线为已合并审计 PR 的最新 main `79aac866426de5df08c90facc35072d6e8e3c341`，未使用任务 003 旧 ZIP 替代。附件提及的 `MFQM-main (3).zip` 当前未提供，因此不声称验证了 ZIP 与仓库的一致性。

## 已实现

1. 默认关闭、操作员显式启用的限时诊断，输出配对 JSONL。记录真实位置差分、求解速度、接触、坠落历史、HP/伤害、纠偏原因，以及可获得的移动包/传送确认时序。Netty 观察器原样转发，不屏蔽或重排原有移动包。实体离开、退出和服务器停止时关闭观察器。
2. 共享的候选运动规则：有限距离的脚部向下扫掠处理首次入射；保留空气中的下落行程，限制首次过量穿透；随后依据材料、深度和输入持续下沉。状态为进入、浸没、离开、外部，均为瞬态数据。玩家本地只预测运动，服务端继续掌握氧气、伤害、状态和位置校验；客户端副本不结算生理状态。
3. 普通玩家不再每 tick 无条件接收 MFQM 速度包及位置传送。超出候选位置预算时仍保留异常纠偏，并记录边界和原因。原有坐骑 LivingEntity 回退保留，未实现或宣称修复船只浮力。
4. 在移动前处理材料造成的受控坠落历史；落地事件另有条件防护。未全局禁用声音、清除外部坠落距离或取消普通摔伤。
5. 测试夹具、延迟代理、状态 PING/PONG 测量工具、受限低 TPS 负载命令及可重现的定时专服测试流程。

原版字节码中的材料差异和快速下落衰减是设计证据；本版本没有旧版完整实机轨迹，因此**不是 1.7.10 数值精确复刻**。

## 自动化结果

保留原有 18 项 JUnit / 15 项 Forge GameTest 的源文件及断言，新增后共 **23 项 JUnit / 20 项 Forge GameTest**。实际构建、测试日志及 XML 随工程交付，最终验证状态以 `TEST_RESULTS.md` 和日志索引为准。新增测试覆盖极端入射、首次穿透、实际实体位移、材料差异、有限值、延迟预算、状态清理、材料内落地及外部真实摔伤。

特别增加了“猪必须真的下落并接触材料”的测试。最初 NoAI 猪夹具导致每轮 18 个高处病例浮空；这些记录已标为无效并保留，随后两套构建各重跑了 27 个自然猪病例，没有拿文件数量冒充通过数量。

## 真实客户端结果

- 基线与候选各有 **54 个有效落入病例**：27 个真实玩家、27 个自然猪，覆盖三种材料 × 1/3/17 层 × 0/3/10 格。每例 260 个服务端采样，首次接触后至少 200 tick。接受矩阵 CSV 明确选取有效记录。
- 三种材料均补录了实际键盘行走、冲刺、单次跳跃和持续跳跃；基线、候选单人存档和候选专服记录分别保留。
- 本轮真实玩家矩阵最大首次记录穿透：基线最高 1.3 格，候选三种材料均为 0.08 格。纠偏总数从 841 次降到 28 次。该比较受到实际环境负载与包合并影响，不是统计性能基准；仍有少量纠偏。
- 独立专服确认 Dev 与 Observer 两客户端同时在线。直连及名义 50/150/300 ms 三档代理，各完成三种材料的 3 层、10 格落入测试。12 个主病例均满足接触后至少 232 tick，HP 最低 20；分别记录 2/1/2/4 次纠偏。代理设置、实测状态 RTT 与玩家移动表现分开报告。
- 原版石地 10 格坠落记录到 7 点摔伤、`entity.player.big_fall` 和 `block.stone.fall`；水中记录到入水事件；实际步行离开松软流沙后落到外部石地，记录到 6 点摔伤与原版着地声音请求。普通外部坠落未变为免伤或静音。
- 低 TPS 平均约 8.2–8.3 TPS，普通及松软流沙实际到达 17 层池底，泥浆保留内部支撑；另完成了真实下界往返、属性恢复与 HUD 清理检查。结果见 `NETWORK_RESULTS.md` 与证据索引。深池测试的临时生命恢复干预必须与普通生存模式数据区别对待。

所有声音结论仅对应实际声音请求回调；No Output 后端不是扬声器听音测试。没有把旧版声音素材加入工程。

## 待用户验收与未证实事项

默认首次穿透上限 **0.08 格**、连续下沉上限 **0.055 格/实体模拟 tick**、深度增益 **0.020** 为可配置候选值，尚未获得玩法验收。低 TPS 时玩家客户端与服务端实体的时钟不同，服务端预算按受限墙钟窗口接受批量移动，不应混用每客户端 tick 与每服务端 tick 的位移。

此前间歇性的 Y 轴抽搐仍为**未确定根因、未证明修复**。少量传送纠偏仍可能可见；真实 WAN 丢包、其他运动模组以及全部人工生命周期组合未得到全面验证。未测项目不会写成通过。
