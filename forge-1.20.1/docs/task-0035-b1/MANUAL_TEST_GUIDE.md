Each suite runs 54 real fixtures: player then pig, three materials × layers 1/3/17 × heights 0/3/10. Each fixture records 260 server ticks, starts every 280 ticks, and must be left connected/unpaused. The suite sets survival, full health/food, a safe respawn and test positions.
